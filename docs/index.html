CyberRiskGuardian Ontology

An OWL 2 ontology for cybersecurity risk assessment, aligned with BFO-2020, with framework vocabularies and a linked library of risk scenarios. Ontologie OWL 2 pour l'appréciation du risque de cybersécurité.

Use with CyberRiskGuardian

A local MCP server and a Python module answer identification questions: which scenarios, techniques, weaknesses, controls and obligations apply to an organisation. See the integration guide.
